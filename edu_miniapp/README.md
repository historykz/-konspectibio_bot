# 🤖 Образовательный центр — Telegram Mini App

Каркас Telegram Mini App для управления учебным процессом: материалы, сдача
работ, запись на зачёты, роли (ученик / куратор / админ).

Это **рабочая база** — поднимается и запускается. Дальше наращиваем функции
по разделам спецификации.

## Что уже работает

- ✅ Запуск приложения из Telegram (кнопка меню + `/start`)
- ✅ Проверка подлинности `initData` на сервере (защита от подделки ID)
- ✅ База данных SQLite со всеми таблицами из спецификации
- ✅ Роли и иерархия доступа (user → student → curator → admin)
- ✅ Главное меню, которое зависит от роли пользователя
- ✅ Экран «Рабочие тетради»: список + отправка файла в чат
- ✅ Экран «Чек-листы», «Мой профиль»
- ✅ Каркас уведомлений и планировщика зачётов (APScheduler)
- ✅ `python manage.py backup` / `stats`

## 📒 Электронный журнал (как Платонус)

- Оценки привязаны к Telegram-ID и защищены подписью — **каждый видит только свои**.
  Отдельный логин/пароль не нужен: Telegram уже подтверждает личность.
- Ученик в разделе «Мои баллы» видит: оценку за каждый урок, свой итог,
  максимальный балл и **место в группе** (рейтинг среди всех учеников).
- Куратор создаёт журналы по предметам, видит полную таблицу (ученики × уроки),
  и **прямо в приложении** добавляет уроки, ставит оценки тапом по ячейке,
  создаёт группы, добавляет/переименовывает/удаляет учеников и меняет их порядок.
- Урок = столбец: тема урока + максимальный балл.
- **Импорт из Google Sheets**: выгрузите таблицу (Файл → Скачать → .xlsx или .csv)
  и отправьте файл боту. Бот распознаёт темы, максимумы и баллы, сопоставляет
  учеников по ФИО и сообщает, кого не нашёл в группе.
- Порядок учеников можно менять (поле `position`).

Формат таблицы для импорта:

| ФИО      | Клетка | ДНК | Эволюция |
|----------|--------|-----|----------|
|          | 10     | 5   | 20       |  ← строка максимальных баллов |
| Алия     | 9      | 5   | 18       |
| Данияр   | 7      | 4   | 20       |

Остальные разделы меню — заглушки «в разработке»: структура и API готовы,
бизнес-логику добавляем на следующих шагах.

## Архитектура

```
Telegram ──> Бот (aiogram)         запуск приложения, уведомления, отправка файлов
        └──> Мини-приложение (frontend/)
                   │  initData
                   ▼
             aiohttp-сервер (webapp/)  проверка подписи + JSON API
                   ▼
             SQLite (database/)
```

```
main.py            — точка входа (бот + веб-сервер + планировщик)
manage.py          — backup / stats
config.py          — настройки из .env
database/          — schema.sql, соединение, репозиторий
bot/               — хендлеры бота, уведомления
webapp/            — auth (проверка initData), api, сервер
services/roles.py  — роли и построение меню
frontend/          — index.html, app.js, styles.css
```

## Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Создайте `.env` из примера и заполните:
   ```bash
   cp .env.example .env
   ```
   - `BOT_TOKEN` — от @BotFather
   - `WEBAPP_URL` — **публичный HTTPS-адрес** (Telegram не открывает http и localhost)
   - `ADMIN_IDS` — ваш Telegram ID (узнать: команда `/id` боту)

3. Получите HTTPS-адрес для локальной разработки (приложение должно быть доступно
   снаружи по https). Например, через cloudflared:
   ```bash
   cloudflared tunnel --url http://localhost:8080
   ```
   Полученный `https://...trycloudflare.com` впишите в `WEBAPP_URL`.

4. Запустите:
   ```bash
   python main.py
   ```

5. В Telegram откройте бота → `/start` → «Открыть приложение».

### Локальный тест в браузере (без Telegram)

Поставьте `DEV_MODE=1` в `.env` — проверка подписи `initData` отключится, и API
можно дёргать из обычного браузера. **На проде обязательно `DEV_MODE=0`.**
